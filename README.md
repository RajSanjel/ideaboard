# IdeaBoard

## Running frontend

- Install [live server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) on your vscode
- Right click on index.html and open with live server.

**Note**: Optionally you can also open the file directly on your browser. Example: path-to-frontend-folder/index.html

## Running backend

- Run the following command
  `npm run dev`
